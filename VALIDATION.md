# Проверки решения

Проверено 8 ноября 2026 года:

- 20 тестов Python unittest: формулы и пороги рейтинга, минимальная выплата
  за целый заказ, несколько товарных строк, количества, проверка данных,
  семидневное окно, paging, границы окна и зависимости DAG.
- Все Python-файлы разбираются с грамматикой Python 3.8.
- SQL выполнен на изолированном PostgreSQL-движке PGlite:
  создание базового DWH с нуля; загрузка Mongo-документов известной структуры;
  измерения заказов, товарные факты, бонусные данные; связь с доставками и CDM;
  повторная миграция; UPSERT фактов; месячные суммы и комиссии;
  доставка после смены месяца; декабрь и январь; повторный расчёт с сохранением ID;
  исправление оценки с пересчётом всего месяца; удаление исчезнувшей группы;
  запрет нескольких доставок одного заказа.

Полный запуск в учебном Airflow 2.3, подключение к реальным MongoDB/PostgreSQL
и обращения к настоящему API доставки в этой среде не выполнялись.
Для проверки совместимости с конкретным тренажёром предусмотрены `tools/preflight.py`,
повторный импорт DAG при установке и `tests/checks.sql`.

Дополнительно проверены: серверная фильтрация по дате заказа, локальные границы
даты доставки и продолжение paging после полностью отфильтрованной страницы.
